# PageTemplates 🪨

Free, standalone HTML pages you can drop onto a site. Currently one page: a "We'll be back soon" maintenance page.

## About

A small personal collection of single-file web pages, free to use without credit. Right now it contains one maintenance page with inline CSS and an image; more templates may be added later. It is meant for anyone who needs a quick static page while a site is down.

## Templates

| Template | Path | Notes |
|----------|------|-------|
| Maintenance page 1 | `Maintenance/Page1/index.html` | Centered image, heading and message; no JavaScript; edit the text and `image.png` to fit your site |

## Getting started

Open `Maintenance/Page1/index.html` in a browser to preview it, or upload the `Page1` folder to your web host and serve `index.html`.

## Tech stack

HTML, CSS
